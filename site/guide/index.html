GUIDE · THREE ROUTES

参与指南

翻译与审校共同构成内容协作，授权协助和可靠分享各自形成独立路径。普通工作留在公开仓库；权利授权与私人联系方式进入项目邮箱。

01

参与翻译与审校

  • 从具备公开改编基础的论文中认领任务。
  • 遵守锁定术语表和四阶段翻译流程。
  • 在 Pull Request 中记录论文 ID、来源版本、模型和修改范围。
  • 合并后按项目贡献规则署名。
  • 修正术语、数字、公式、引用、格式和中文表达。
  • 让建议指向具体论文、段落或可复核依据。
  • 小范围问题提交 Issue，确定性修改提交 Pull Request。
  • 人工审校记录继续保留在论文元数据中。
阅读贡献说明提出问题提交修改
02

协助申请翻译权限

  • 原作者或权利人可向项目邮箱提供范围明确的书面授权。
  • 合作者、朋友或学术联系人可以帮助转达项目请求。
  • 不要公开作者私人邮箱，也不要进行批量骚扰式联系。
  • 授权必须由有权许可的人给出；介绍人不能代替权利人作出授权。
通过项目邮箱协助阅读权利协议
03

分发和宣传

  • 分享公开网站、公开译文和 GitHub 仓库。
  • 在课程、读书会、研究群体和社交媒体中介绍项目。
  • 始终保留“非官方社区项目”说明。
  • 不得分发等待授权的完整译文或本地隔离产物。
