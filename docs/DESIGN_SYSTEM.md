# Snowmass 中文开放翻译视觉设计系统

## 目标

网站需要同时表达三件事：Snowmass 的识别线索、学术档案的可信度，以及机器翻译协作项目的动态进度。新版以“雪线科研图谱”为主视觉，并将此前探索的“冰晶粒子场”和“极地文献馆”分别保留给数据型页面与论文档案页面。

设计不能削弱项目最重要的权利原则：仅当公开权利清单中 `publication_allowed: true` 时，完整译文才可进入公开发布流程。视觉状态必须继续清楚区分已核验、等待授权和禁止公开。

## 统一语言

### 核心意象

- 雪山与雪线代表规模、探索和长期建设，不暗示 Snowmass 官方背书。
- 等高线和地形网格代表论文索引、学科结构与研究路径。
- 冰晶和粒子轨迹仅用于翻译流水线、进度统计等计算型页面。
- 暖白纸张、细线和档案编号用于论文详情、授权记录与长文阅读。

### 配色

- 雪白 `#F7FAFA`：页面底色。
- 冰雾 `#E7F0F2`：区块和输入控件底色。
- 深岩 `#14272F`：主文字。
- 冰川蓝 `#6FA6B8`：品牌、链接和焦点状态。
- 松针绿 `#357261`：许可证已核验、允许发布。
- 日照琥珀 `#A76A13`：等待许可、机器初稿和人工审校中。
- 警戒红 `#A84C48`：禁止公开、拒绝授权和撤回。

正文颜色和状态颜色应满足 WCAG AA 对比度。状态不能只依赖颜色，必须同时显示文字标签。

### 字体与层级

- 大标题使用系统可用的宋体/衬线字体栈，形成学术出版物气质。
- 正文、导航和控件使用系统无衬线字体，保证中文界面清晰。
- arXiv 编号、数据和元信息使用等宽字体。
- 不引入外部字体依赖，降低隐私、性能和托管成本。

## 页面分工

### A：雪线科研图谱

用于首页、总目录和 Frontier 导航。首页首屏使用真实雪山摄影，并以半透明浅色渐变确保中文标题可读。等高线作为低对比度装饰，不遮挡正文。首屏之后回归纯白资料库界面。

首页结构：

1. 吸顶浅色导航：论文目录、翻译进度、授权档案、项目说明、GitHub。
2. 雪山主视觉：项目定位、权利声明和两个主要行动入口。
3. 四项实时统计：论文数、可公开翻译数、需额外授权数、总页数。
4. 权利与翻译工作流说明。
5. 可检索、筛选和排序的论文目录。

### B：冰晶粒子场

用于翻译进度、模型运行记录和贡献统计。以浅蓝到淡紫的光谱渐变、抽象冰晶和粒子轨迹构成图表背景。它是 A 的功能子语言，沿用相同导航、字体、边框、按钮和状态色。

### C：极地文献馆

用于论文详情、译文阅读、来源许可证、授权通信和版本历史。采用暖白背景、编辑式排版、细线分隔和纪实雪景切片。数据来源、许可证链接、模型版本、人工审校者和变更记录优先于装饰。

## 图片策略

- 首版使用一张可合法复用的真实雪山图片作为首页视觉，仓库必须记录作者、来源、许可证和原始链接。
- 上线前将图片优化为本地 AVIF/WebP/JPEG 多格式资源，不依赖第三方图片热链。
- 图片只作为装饰时使用空 `alt`；承载信息时提供准确中文替代文本。
- 合成图必须注明生成工具、日期、提示词摘要和后期修改，并避免模仿在世艺术家风格。
- 不使用与 Snowmass 官方标志近似的图形，不制造官方合作或认可的印象。

## 组件行为

- 导航在桌面端保持轻薄透明，在移动端折行或收拢为可访问菜单。
- 筛选器保留所有现有字段及 URL 状态同步；视觉改造不得改变查询结果。
- 论文卡片采用白底细边框，悬停仅轻微抬升；题名、作者和三类状态是主要信息。
- 详情页沿用现有路由参数和返回行为，但切换为“极地文献馆”排版。
- 动画遵守 `prefers-reduced-motion`，不采用大面积视差和自动播放视频。

## 响应式与性能

- 桌面端主视觉为左右信息构图；窄屏使用更强遮罩并把文案置于图片上方。
- 目录从三列依次降为两列和单列，触控目标不小于 44px。
- 首屏图片应控制尺寸并设置固定纵横比，避免布局偏移。
- 无 JavaScript 时仍显示项目说明与权利原则；目录加载失败时提供明确错误信息。

## 验收标准

- 主页整体为偏亮、偏白的雪景视觉，不残留原先黑底荧光绿主语言。
- 三种子语言在颜色、字体、圆角、间距和导航上保持同一品牌体系。
- 541 篇目录数据及统计仍从现有清单动态加载，不硬编码生产数量。
- 筛选、排序、分页、论文详情、URL 状态和返回操作行为不回归。
- 桌面与移动视口均无水平溢出，键盘焦点可见，状态信息不只依赖颜色。
- 页面继续明确声明非官方身份、版权范围与发布闸门。
