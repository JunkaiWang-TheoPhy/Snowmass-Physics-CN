# Snowmass 双语护眼站设计

## 目标

把当前偏亮的单语静态目录改为可长时间阅读的双语站点。采用已确认的 B「雾蓝石板」视觉方向，在右上角提供相互独立的一键语言和明暗模式切换。

## 视觉系统

- 浅色模式使用低饱和雾蓝灰背景、蓝黑正文和略亮的卡片层级，不使用纯白作为大面积底色。
- 深色模式使用午夜蓝灰背景、柔和灰蓝正文和稍亮的卡片层级，不使用纯黑。
- 两种模式保持同一信息层级、状态色语义、键盘焦点和可读对比度。
- 首次访问的主题跟随 `prefers-color-scheme`；用户手动选择后写入 `localStorage`。

## 双语行为

- 右上角语言按钮在中文与 English 之间即时切换，不刷新页面。
- 首次访问优先接受 `?lang=zh` 或 `?lang=en`；否则读取用户保存值，再参考浏览器语言。
- URL 始终同步当前语言，因此英文视图可以直接分享。
- 页面导航、说明、指标、筛选器、排序、分页、状态标签、详情字段、空状态和错误状态均有中英文文案。
- 英文论文标题是来源标题和唯一规范标题，不被改写。
- 每条公开记录增加 `title_zh`、`title_zh_status` 和 `title_zh_model`。首批中文译题均标记为 `machine-draft`，允许后续 PR 人工修订。
- 中文模式在英文主标题下显示更小、更浅的中文译题，不额外显示“机器译名”标签；英文模式隐藏中文译题。机器生成状态仍保留在详情元数据中。
- 搜索同时匹配英文和中文标题，不因当前界面语言改变检索能力。

## 数据与权利边界

- 中文译题属于项目生成元数据，不改变原论文许可证、授权判断或全文发布闸门。
- 生成器从独立、可审计的中文标题映射文件合并字段；缺失、重复或身份不匹配必须让测试失败。
- 不把机器译题写回原始内部目录，也不声称机器译题经过作者确认。

## 可访问性与兼容性

- 两个切换按钮使用真实 `button`、明确的可访问名称、焦点样式和 `aria-pressed` 状态。
- 在脚本加载前用内联启动代码应用保存的主题，避免亮色闪烁。
- 无 JavaScript 时仍可阅读默认中文静态页面和原始英文论文标题。
- 桌面端右上角并排显示两个开关；移动端保留图标和短标签，不挤压品牌名称。

## 验收标准

1. 541 条记录全部具有非空 `title_zh`，且原始 `title` 未改变。
2. 中文模式全部显示中英双标题；英文模式只显示英文标题。
3. 所有公共界面文案可以切换为英文，语言状态写入 URL 和本地存储。
4. 浅色与深色模式均完整覆盖页面，首次访问跟随系统、手动设置可恢复。
5. 搜索可命中中文译题；筛选、排序、详情和分页在两种语言下正常工作。
6. 权利数据、授权状态和 `publication_allowed` 不因本功能改变。
7. 自动化测试、公共树审计、视觉检查和 Netlify 生产部署全部通过。
