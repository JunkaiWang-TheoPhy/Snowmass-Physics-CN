# Bilingual Cultural README Design

## Intent

Turn the repository landing page from an engineering inventory into an inviting editorial threshold for the Snowmass translation project.

## Design

- Use the project's snow-mountain panorama as a wide, lightweight banner.
- Keep Chinese as the default `README.md`; add `README.en.md`, with reciprocal language links at the top.
- Lead with a short project line, three reader-oriented destinations, and two verified literary/scientific quotations.
- Keep only three public scale indicators: 541 papers, 10 Frontiers, and 273 sources permitting adaptation.
- Organize the narrative around the atlas, translation as inheritance, the publication gate, and participation.
- Move readers to existing protocol and contribution documents instead of duplicating technical implementation details.

## Boundaries

- Preserve the distinction between project licensing and source-paper/translation rights.
- Do not imply official affiliation with Snowmass or related institutions.
- Do not embed a third-party screenshot; reuse a project-owned generated landscape crop.
- Verify quotation wording and attribution against linked sources.

## Acceptance

Both README files render from repository-relative assets, link to one another and the bilingual production site, include the rights boundary, and avoid commands, source-tree diagrams, token counts, and implementation detail.
