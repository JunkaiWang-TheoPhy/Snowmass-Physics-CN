> **“路漫漫其修远兮，吾将上下而求索。”**<br>
> —— 屈原《[离骚](https://www.gushiwen.cn/mingju_1619.aspx)》

Snowmass 汇集了粒子物理共同体对未来的想象。我们希望为这片辽阔的知识版图铺设一条中文路径：从机器初译出发，经由术语整理、同行审校与一次次 Pull Request，让论文越过语言的边界，也保留它们来时的出处、条件与尊严。

这不是一座已经落成的纪念碑，而是一条仍在延伸的山路。

## 让译文像知识本身一样可以传承

> **“If I have seen farther, it is by standing on the shoulders of giants.”**<br>
> — Isaac Newton, [letter to Robert Hooke, 1676](https://newtonproject.ox.ac.uk/view/texts/normalized/OTHE00101)

机器负责迈出第一步，人来决定这段文字最终能走多远。译文会记录所用模型、术语修订与人工审校；任何人都可以指出误译、校正公式、改善表达，或认领一篇尚未完成的论文。

每一次修改都应让后来者看得更远，而不是抹去前人的足迹。

## 权利先于公开

翻译是一种改编。只有当来源许可证允许改编，或权利人给出范围明确的书面授权时，我们才公开完整译文。授权尚不清楚的论文仍会保留原文入口和工作进度，但不会越过出版边界。

这是一个非官方、非营利的开放协作项目，不代表 Snowmass、SLAC、arXiv、作者、合作组或出版机构。更完整的规则可见[权利与发布协议](docs/RIGHTS_PROTOCOL.md)。

## 与我们同行

你不必一次翻译整篇论文。一个术语、一处公式、一段更自然的中文，都是这张地图的一部分。

- 浏览[公开网站](https://snowmass-physics-cn.netlify.app/?lang=zh)，选择感兴趣的论文；
- 阅读[参与指南](CONTRIBUTING.md)，提交翻译、审校或资料修订；
- 在 Pull Request 中留下依据，让每一次改动都可追溯；
- 项目联系：[WangTheoPhys@outlook.com](mailto:WangTheoPhys@outlook.com)。
